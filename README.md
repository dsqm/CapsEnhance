# CapsEnhance

Windows **CapsLock** 快捷键增强程序：按住 `CapsLock`（下称 **C**）当修饰键，把它变成一套贴身的编辑 / 窗口 / 滚动工具。

- 便携免安装：不写注册表、不改系统设置，卸载 = 删掉整个目录。
- 常驻系统托盘，可随时暂停 / 重启 / 退出。
- **CapsLock 被本程序拦截**：需要真实大小写切换时按 `C + Tab`（发送一次真的 CapsLock），或从托盘点"暂停映射"。

## 快速开始

1. 四个 exe（`CapsEnhance.exe` / `CapsEnhanceSettings.exe` / `CapsEnhanceHelp.exe` / `CapsEnhanceInfo.exe`）放**同一目录**，双击 `CapsEnhance.exe` 运行。
2. 托盘右键菜单：**程序文件夹 / 暂停映射 / 取消全部置顶 / 设置… / 重启程序 / 退出**。
3. 单实例运行；需要管理员权限时在设置里开 `RunAsAdmin = 1`（默认关）。

## 键位总览

按住 `CapsLock`（下称 **C**）进入映射模式，按下触发键生效，松开 C 恢复原样。

| 按键 | 作用 |
| --- | --- |
| `I` `J` `K` `L` | ↑ ← ↓ → |
| `P` / `;` | Home / End |
| `-` / `=` | PgUp / PgDn |
| `R` / `W` | Backspace / Delete |
| `Space` | Enter |
| `N` / `O` | 按词向左 / 右跳 |
| `D` 或左 `Alt` | **增强键**：动作连发 3 次（`C+D+J` = 连移 3 格） |
| `F` | **选区键**：相当于按住 Shift（`C+F+J` = `Shift+←`） |
| `Q` | 当前窗口挪到鼠标光标处（支持多屏） |
| `T` | 当前窗口**置顶 / 取消置顶**（外圈边框 + 提示音，见下） |
| `F4` | 打开当前程序所在文件夹并选中它的 exe |
| `F12` | 弹出**窗口信息**：列出前台窗口与所属进程的详细信息（可编辑文本） |
| `C` | **超级复制**：取光标下控件的文本进剪贴板，并在屏幕下方弹出预览（取不到也显示原因，见下） |
| `F6` / `F7` / `F8` | 系统静音（开关）/ 音量减 / 音量加（后两条长按连续调） |
| `F1`（按住） | 按键帮助图 |
| `Tab` | 发送一次真实 CapsLock |
| 反引号（`） | 开始 / 结束记录日志 |
| 滚轮 | 快速滚动（倍数可配） |
| `Alt/D` + 滚轮 | 持续滚动（同向再滚提速，反向滚停） |
| `Shift` + 滚轮 | 横向滚动 |
| 按住 C + 左键拖动 | 拖动光标下的窗口 |
| 单击 `Caps` / 左 `Shift` / 右 `Shift` | 切中文 / 英文 / 中文（可配，见下） |

> `C` 必须第一个按下，修饰键要在动作键之前按住。例：`C+D+F+J` = 连续 3 次 `Shift+←`（一次选中 3 个字符）。

下面挑几项需要说明的展开。

### 按词跳转：`N` / `O`

**按词跳转**：读取目标程序的真实文本、按"连续同类算一个词"跳边界，中英数字混排比 `Ctrl+方向` 稳：

- 默认不跨行，只在行头/行尾才跨到相邻行。
- 距离小或程序不支持"直接置位"时退回逐格发方向键（上限见 `MaxArrowSteps`）；
  读不到文本时退回原生 `Ctrl(+Shift)+方向`。全程限时，不会冻住键盘。
- 已支持：经典 Edit / RichEdit、**EmEditor**、Scintilla 系（Notepad3 / Notepad++ / SciTE）、UIA（QQ、Edge 等）、IAccessible2、**WPS 文字**（COM）。
- 读不到 / 不合适的程序把进程名写进 `[NativeWordJump]` 名单，直接发 `Ctrl+方向`。

### 窗口

**`C + Q` 挪窗到光标处**

- 窗口左上角对齐光标，整窗钳进光标所在显示器的工作区，挪完一定整窗可见。
- 最大化窗口在**另一块屏**时：还原 → 挪 → 再最大化；光标就在本屏时不动。全屏窗口不动。
- 目标程序若又把自己挪走（吸附类工具），自动回读补发（最多 3 次）。

**`C + 左键` 拖动窗口**

- 移动光标下的**顶层窗口**，不必先够到标题栏；不抢焦点，点击不穿透。
- 最大化窗口先拖出 20px 才跟手，普通窗口按下即跟手；松开左键或 C 结束。
- 全屏 / 最小化 / 桌面 / 任务栏不接管。命中两份拖动黑名单（`[DragWindowBlacklist]` 按类名 / `[DragProcessBlacklist]` 按进程名）的窗口透传。

### 窗口置顶：`C + T`

按一下把**当前窗口**钉在最上层，再按一下放开。这一块是**直接移植 PowerToys 的
AlwaysOnTop 模块**（窗口模型、事件、定时器、D2D 绘制都同源，见
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#窗口置顶pincppct)）：

- 钉住的窗口外面套一圈**圆角边框**：粗细 2px（随显示器 DPI 缩放）、跟随系统
  **强调色**、Win11 上圆角半径跟随窗口自己的圆角设置（Win10 直角）。
  PowerToys 的几何是"环从窗外 1px 起、向内压 1px"，所以看到的是约 1px 的细线。
- 钉住响一声 `Speech On`，放开响一声 `Speech Sleep`（都是系统自带音效，
  跟随"声音方案"，静音方案下自动安静）。
- 边框不抢焦点、点它不会有任何反应（与 PowerToys 同款：边框窗 `WS_DISABLED`
  且不改光标）；它只在外挑的那一两像素上占位，不影响窗口本身的操作。
- 可以同时钉多个窗口（上限 32 个）；托盘菜单的**取消全部置顶**一次全放，
  没有置顶时该项置灰。
- 边框跟随窗口移动 / 缩放 / 最大化 / 还原；窗口最小化时边框隐去，恢复时
  重新置顶并画回来；切到别的虚拟桌面时边框也跟着隐去。
- 不接管桌面 / 任务栏 / 本程序自己的窗口；命中 `[AutoDisable]` 时整段不介入。
- 退出或重启程序会**解除全部置顶**（窗口回到原来的层级）；**暂停映射不会**
  动已钉的窗口 —— 暂停只停按键。

> 目标窗口以管理员身份运行时，非提权的本程序改不动它：会弹托盘气泡提示，
> 需要置顶这类窗口请开 `RunAsAdmin = 1`。

### 单键切输入法（单击 Caps / 左右 Shift）

**单击**（按下后很快松开、不做别的）把输入法**强制**切到固定一边，不存在"按反了"：

| 单击 | 强制切到 | 配置项 |
| --- | --- | --- |
| `CapsLock` | 中文 | `ImeCapsMode` |
| 左 `Shift` | 英文 | `ImeLShiftMode` |
| 右 `Shift` | 中文 | `ImeRShiftMode` |

- 模式值：`0` = 不处理、`1` = 中文、`2` = 英文，三键各自独立。
- **前提是当前不是英文键盘**：本程序只切中/英状态，不替你换键盘布局；停在英文键盘上时三键都没反应（刻意行为）。
- "单击"判定：Caps = 按住期间没触发任何 `C+` 动作（无时间上限）；Shift = 期间没按别的键且 ≤ 300ms（不影响 `Shift+A` 这类组合）。
- 遵守 `[AutoDisable]` 名单；切换只改中英位，保留全角 / 符号等其它转换模式。

```ini
[General]
ImeCapsMode   = 1   ; Caps    -> 中文
ImeLShiftMode = 2   ; 左Shift -> 英文
ImeRShiftMode = 1   ; 右Shift -> 中文
```

### 滚轮（按住 C）

| 组合 | 行为 |
| --- | --- |
| `C + 滚轮` | 快速滚动：滚一格当 N 格（`WheelScrollMul`） |
| `C + Alt/D + 滚轮` | **持续滚动**：滚一下就一直滚，同向再滚逐档提速，反向滚立即停 |
| `C + Shift + 滚轮` | 横向滚动（方向与系统约定一致） |

判定顺序：Shift（横向）→ Alt/D（持续）→ 快速滚动。

持续滚动细节：按任意键 / 鼠标键终止（系统自动重复不算）；松开 C **不**终止；超过 10 分钟无操作自动停。手感是"不足一格的小刻度"（像触控板），不累积小刻度的程序写进 `[NoSmoothScroll]` 改发整格。

### 按键帮助：`C + F1`

**按住** `C + F1` 浮出一张半透明键位图（完整键盘，功能印在键帽上），松开任一键即消失。

- 不抢焦点，可以一边按着看一边操作；底部列出滚轮、输入法、拖动这些"非单键"功能。
- 由独立的 `CapsEnhanceHelp.exe` 画（主程序崩了也不会留下关不掉的图）；单击 Caps / Shift 三条的文案跟随 `Ime*Mode` 配置。
- 直接双击 `CapsEnhanceHelp.exe` 可单独看图：显示、点一下关闭，3 分钟自动收。

### 窗口信息：`C + F12`

弹出一个**可编辑的文本窗口**，列出开火那一刻前台窗口的详细资料。

- **窗口层**：标题、类名、是否 Unicode、句柄与「窗口唯一 ID」、控件 ID、状态（可见性断开会说明是"自己没 WS_VISIBLE"还是"被父 / 祖先隐藏"）、是否被 DWM 隐藏、**截图保护（显示亲和性：能不能被截图 / 录屏看见）**、**分层透明度（alpha / 颜色键）**、**所在桌面（安全桌面上的窗口既截不到也抓不到焦点）**、窗口/还原/客户区矩形、所在显示器与工作区、窗口 DPI 与 DPI 感知、父/所有者/根/根所有者窗口、是否顶层、线程；调试向还列菜单句柄、实例句柄、窗口过程、窗口 USERDATA、类额外空间 / 类原子 / 类样式、窗口字体、AppUserModelID、默认 IME 窗口、样式与扩展样式的数值和符号（含 `WS_EX_NOREDIRECTIONBITMAP`：带这一位就没有重定向表面，`PrintWindow` 截出来全黑）。
- **进程层**：进程名、PID、程序路径、映像类型（子系统 / EXE·DLL / 是否 .NET）、架构、命令行、当前目录、启动时间、父进程**及其创建时间**（用来排除父 PID 被复用）、是否关键进程（结束它会蓝屏）、是否在 Job 里（受 Job 的资源 / UI 限制）、账户与用户 SID、完整性级别、是管理员还是标准用户运行、UIAccess 标志（令牌上那一位，别和清单里的 `uiAccess` 声明混为一谈）、完整性策略（禁写高 / 禁读高）、令牌限制（普通 / 曾被 UAC 过滤 / 受限令牌）、UAC 虚拟化（允许 / 已启用分两档）、关联令牌（拆分令牌的高权那一半是否存在）、容器（AppContainer / 沙箱 / AppSilo / 私有命名空间）、能力数与包 SID、登录会话 SID、保护级别（PPL）、缓解策略（ASLR / CFG / ACG / 禁止动态代码 / 禁止 Win32k 调用 / 禁止子进程 / 禁止加载字体 / 映像加载限制 / 禁用扩展点 / 系统调用过滤 / 侧信道隔离 / 用户态影子栈 / 重定向信任）、已启用特权、UWP 包名、会话、句柄数、工作集、优先级类、文件版本 / 产品名 / 公司。
- **子窗口树**：深度 8 / 至多 400 条，每条带类名、标题与矩形。

- 由独立的 `CapsEnhanceInfo.exe` 承载：枚举窗口树、读进程令牌这些调用可能卡在无响应或被保护的进程上，主线程是键盘钩子宿主，不能碰。
- **不置顶**、**不自动折行**（长值靠横向滚动看全）；每行都是「键: 值」，值不会被拆成无键名的续行，冒号后的值按制表位对齐。
- **两个视图**（顶部一栏左侧切换）：**常用**按设置里排好的一批字段平铺显示；**全部**是上面那份全量分组信息（`[...]` 段头整行加粗 + 强调色）。两个视图都可编辑，各留一份自己的文本，来回切不互相覆盖。默认常用。
- `Tab` 在常用 / 全部之间切换；滚轮逐帧平滑滚动，`Shift+滚轮` 横向滚动。
- 顶部**筛选**：键入即只留下包含该词的行（键或值都算，不区分大小写），筛选期间标题栏带一句命中行数；`Esc` 清空筛选、恢复全文。筛选期间文本框只读 —— 过滤结果与原文没有逐行对应关系，在其上改字说不清改的是哪一行。
- 可编辑（`Ctrl+Z` / `Ctrl+C` / `Ctrl+A` 等），右键菜单里另有撤销、剪切、粘贴、删除、全选与**刷新**（`F5` 不绑）；关窗时把当前尺寸写回 `InfoW` / `InfoH`。
- **双击 `CapsEnhanceInfo.exe` 也能直接用**：没有主程序牵线时，它自己挑目标（当前前台窗口 → 指针下的窗口 → 桌面）并立刻出资料；右键菜单里的「瞄准窗口（点击取样）」可以再换目标（鼠标变十字，点哪个窗口就看哪个）。
- 再按一次 `C+F12` = 刷新到新的前台窗口并前置，不会开出第二个窗口。宿主窗口下带 `Windows.UI.Core.CoreWindow` 子窗口的 UWP 应用会换算成应用自己的进程（与 `C+F4` 同一判定）；没有该子窗口的新版窗口（如 Win11 设置）仍显示 `ApplicationFrameHost.exe`，弹窗里会注明原因。
- 字体在设置程序「窗口信息」段里点「选择字体…」挑（也可直接改 `InfoFont`）；**常用的字段与顺序**在设置程序同一段下面的列表里增删排序（也可直接改 `InfoCommonFields`），右侧「重置默认」一键回到那 11 项；`Esc` 或标题栏 X 关闭。

### 超级复制：`Caps` + `C`

把**光标指针下那个控件里的文字**取出来放进剪贴板，然后在你眼前晃一下确认——之后在别处 `Ctrl+V` 即可。

- **怎么取**：不模拟"全选 → 复制"，而是走**无障碍树**（UI Automation / MSAA）按坐标查元素，读它暴露的 `Name` / `Value` / `Description`。所以它**和控件能不能选中、有没有焦点、是不是只读或禁用都无关**：只读输入框、禁用的按钮、网页正文、`F12` 弹窗里的文本都能取。
- **只取一个字段，按元素类别挑**：输入框只取 `Value`（`Name` 往往是"在此处输入你的搜索…"这类占位提示，拼进去就是多出来的第一行）；容器（窗口 / 窗格 / 文档 / 分组）**只认 `Value`** —— 记事本这类多行编辑框在无障碍树里就是"文档"，正文在 `Value` 里；而浏览器网页的"文档"没有 `Value`（正文只走 TextPattern），它的 `Name` 才是页面标题，所以指针停在网页空白处会**如实失败**而不是复制出标题；链接取 `Name`（可见文字）。取不到就说失败，**不往父链上爬**去找"看起来有字"的祖先，否则光标位置与复制内容会失去对应关系。
- **为什么用指针而不是焦点**：按住 Caps 时焦点常常还留在上一个窗口，指针才是"我要复制这一行"唯一不会撒谎的指向。
- **容错**：命中到窗口 / 窗格 / 文档这类容器角色时会**在同一坐标再查一次**（不然浏览器与资源管理器经常只取到壳）；遇到懒加载控件会在 600ms 预算内按 200ms 间隔最多尝试 3 次（首次 + 最多 2 次重查）；整个查询有超时，目标卡死也不会把本程序拖住（取词跑在执行线程上，主线程是钩子宿主）。
- **浮层**：不抢焦点、点击穿透、不进 Alt+Tab，默认停在**所在显示器工作区的 90% 高度处水平居中**（90% 是顶边的锚点；更靠下时会被「底边距工作区底 8px」钳住，所以高内容等效贴底、内容越高越往上浮），成功 1.8 秒 / 失败 2.8 秒后自动消失（都可配）。顶部小字是**来源程序**，**字数 / 行数贴在同一行右侧**（单行文本只显示字数，真多行时才带「· N 行」；字数按**码点**计：`𰻝`、emoji 这类代理对算一个字）。字体与字号可调（`CopyFont` / `CopyFontSize`；标题行取正文的 90%，留白跟着放大），按该屏 DPI 缩放。正文超过 10 行 / 500 字用 `…` 截断，**剪贴板里永远是全文**。再按一次 `Caps` + `C` 会先关掉上一张。
- **失败也会显示，而且会说原因**：光标下没有可识别控件 / 这个控件没暴露文字 / 这个输入框是空的 / 该程序没开无障碍（Chromium 系的渲染器兜底壳）/ 目标程序权限更高（需同权限运行）/ 目标无响应 / 取词线程没能启动（本机资源不足）/ 剪贴板被占用 / 取到的是空文本。失败时**剪贴板一个字节都不动**（不会像某些工具那样把"没取到"这类占位词写进去）。
- **清洗**：换行统一为 CRLF 写进剪贴板，并按 `CopyStripTail` 去掉**尾部**空白与换行（内部换行与缩进原样保留）。
- 实现参考了 [Textify](https://github.com/rammichael/Textify) 的取词思路（GPL-3.0），但查询限时、失败分类、浮层与配置都是本项目的，详见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) 第 6 条。
#### 注意事项
1. 在浏览器中使用 
    - Firefox、Edge 及 IE 浏览器默认无需任何额外设置。
    - 若发现在 Firefox 中无效，请在地址栏中输入并打开 about:config ，确保 accessibility.force_disabled 值为 0。
    - 使用 Chromium 内核的浏览器，请在地址栏中输入并打开 chrome://accessibility ，勾选 Native accessibility API support 以及 Web accessibility 。
    - 注意，部分浏览器，如 360极速，不受该设置控制，动作无法在此类浏览器中使用。
    - 部分 Chromium 内核的浏览器，如 Vivaldi ，重启后会关闭无障碍功能，如果希望每次打开浏览器时自动启用，请给它的启动命令添加参数 --force-renderer-accessibility 。
2. 在 Electron 应用中使用
    - 常见的 Electron 应用有 VSCode、Typora、Eagle、洛雪音乐助手……可到 Electron 官网 了解更多。
    - 已启用屏幕阅读器（讲述人、 JAWS ……），或 Electron 应用已开启无障碍功能的情况下， 默认无需任何额外设置。
    - 若不属于上述情况，请给应用的启动命令加上参数 --force-renderer-accessibility 。

### 日志：C + 反引号

- 开始 / 结束记录，日志写在 exe 同目录 `log\` 下，**每次记录新建一个文件**；平时不写。
- 开始 / 结束各响一声不同的系统提示音（都走系统声音方案，可改可静音）。
- 结束时弹的托盘气泡**可点击**：打开 `log\` 目录并选中这份日志（与 `C+F4` 同一条 shell 链路）。
- 记录期间会写焦点控件的文本样本（前 160 字符）与跳转位置 —— **敏感内容慎开**。
- 启动时静默采集一次环境基线（位宽 / 钩子 / 权限 / 键盘布局 / UIA 可用性），记录时一并输出。

## 注意事项 / 常见问题

- **Caps 必须第一个按下**：`Alt + C + J` 这种反着按不生效（修饰键会卡住）；`C + J + Alt`（先 J 后补 Alt）那一次就是普通左移 —— 不做补正换来"按下即响应"。
- **`C + Q` 没反应**：前台是桌面 / 任务栏 / 本程序自己，或命中 `[AutoDisable]`，或前台是全屏窗口、或是已最大化且光标就在本屏 —— 都是故意不挪。记录模式（C + 反引号）下 `[窗口]` 行有判定结果。
- **自动屏蔽没生效**：判据是前台窗口所属进程，进程名要和任务管理器"详细信息"页的映像名一致；后台 / 服务的窗口不算前台。
- **WPS**：只支持 `wps.exe`（表格 / 演示的对象模型不同）；`RunAsAdmin=1` 时自动走一个普通权限小进程代读。不生效先看日志的 `[桥]` / `[桥WPS]` 段。
- **体量上限**：经典 Edit 通道 64000 字符、Scintilla 2 MB（字节）、WPS 100000 字符，超出直接退回原生 `Ctrl+方向`。
- **重启 / 退出会清卡键**：对所有键补发抬起（`CapsLock` / `NumLock` / `ScrollLock` 这类开关键除外），**不限于本程序造成的**——别的程序崩溃留下的卡键同样清掉（判定"系统认为按着 && 钩子没见到你物理按下"，所以你正按着的键不受影响）。已知边界：**启动**那一遍比较保守（启动前就按着的键分不清"你在按"还是"已卡住"，一律保护），上次崩溃残留的修饰键卡键若没被清掉，**再重启一次**即可。
- **排障命令**：`CapsEnhance.exe --restart` 请求运行中的实例重启（本体没在跑时会照常启动）。
- **卸载** = 删目录。只落地 `CapsEnhance.ini`、`log\`、进程内钩子（退出即消失）。
