# CapsEnhance

Windows **CapsLock** 快捷键增强程序：按住 `CapsLock`（下称 **C**）当修饰键，把它变成一套贴身的编辑 / 窗口 / 滚动工具。

- 便携免安装：不写注册表、不改系统设置，卸载 = 删掉整个目录。
- 常驻系统托盘，可随时暂停 / 重启 / 退出。
- **CapsLock 被本程序拦截**：需要真实大小写切换时按 `C + Tab`（发送一次真的 CapsLock），或从托盘点"暂停映射"。

## 快速开始

1. 三个 exe（`CapsEnhance.exe` / `CapsEnhanceSettings.exe` / `CapsEnhanceHelp.exe`）放**同一目录**，双击 `CapsEnhance.exe` 运行。
2. 托盘右键菜单：**程序文件夹 / 暂停映射 / 取消全部置顶 / 设置… / 重启程序 / 退出**。
3. 单实例运行；需要管理员权限时在设置里开 `RunAsAdmin = 1`（默认关）。

## 键位总览

按住 `CapsLock`（下称 **C**）进入映射模式，按下触发键生效，松开 C 恢复原样。

| 按键 | 作用 |
| --- | --- |
| `I` `J` `K` `L` | ↑ ← ↓ → |
| `P` / `;` | Home / End |
| `-` / `=` | PgUp / PgDn |
| `R` / `W` | Backspace / Delete |
| `Space` | Enter |
| `N` / `O` | 按词向左 / 右跳 |
| `D` 或左 `Alt` | **增强键**：动作连发 3 次（`C+D+J` = 连移 3 格） |
| `F` | **选区键**：相当于按住 Shift（`C+F+J` = `Shift+←`） |
| `Q` | 当前窗口挪到鼠标光标处（支持多屏） |
| `T` | 当前窗口**置顶 / 取消置顶**（外圈边框 + 提示音，见下） |
| `F3` | 打开当前程序所在文件夹并选中它的 exe |
| `F6` / `F7` / `F8` | 系统静音（开关）/ 音量减 / 音量加（后两条长按连续调） |
| `F1`（按住） | 按键帮助图 |
| `Tab` | 发送一次真实 CapsLock |
| 反引号（`） | 开始 / 结束记录日志 |
| 滚轮 | 快速滚动（倍数可配） |
| `Alt/D` + 滚轮 | 持续滚动（同向再滚提速，反向滚停） |
| `Shift` + 滚轮 | 横向滚动 |
| 按住 C + 左键拖动 | 拖动光标下的窗口 |
| 单击 `Caps` / 左 `Shift` / 右 `Shift` | 切中文 / 英文 / 中文（可配，见下） |

> `C` 必须第一个按下，修饰键要在动作键之前按住。例：`C+D+F+J` = 连续 3 次 `Shift+←`（一次选中 3 个字符）。

---

下面挑几项需要说明的展开。

### 按词跳转：`N` / `O`

**按词跳转**：读取目标程序的真实文本、按"连续同类算一个词"跳边界，中英数字混排比 `Ctrl+方向` 稳：

- 默认不跨行，只在行头/行尾才跨到相邻行。
- 距离小或程序不支持"直接置位"时退回逐格发方向键（上限见 `MaxArrowSteps`）；
  读不到文本时退回原生 `Ctrl(+Shift)+方向`。全程限时，不会冻住键盘。
- 已支持：经典 Edit / RichEdit、**EmEditor**、Scintilla 系（Notepad3 / Notepad++ / SciTE）、UIA（QQ、Edge 等）、IAccessible2、**WPS 文字**（COM）。
- 读不到 / 不合适的程序把进程名写进 `[NativeWordJump]` 名单，直接发 `Ctrl+方向`。

### 窗口

**`C + Q` 挪窗到光标处**

- 窗口左上角对齐光标，整窗钳进光标所在显示器的工作区，挪完一定整窗可见。
- 最大化窗口在**另一块屏**时：还原 → 挪 → 再最大化；光标就在本屏时不动。全屏窗口不动。
- 目标程序若又把自己挪走（吸附类工具），自动回读补发（最多 3 次）。

**`C + 左键` 拖动窗口**

- 移动光标下的**顶层窗口**，不必先够到标题栏；不抢焦点，点击不穿透。
- 最大化窗口先拖出 20px 才跟手，普通窗口按下即跟手；松开左键或 C 结束。
- 全屏 / 最小化 / 桌面 / 任务栏不接管。命中两份拖动黑名单（`[DragWindowBlacklist]` 按类名 / `[DragProcessBlacklist]` 按进程名）的窗口透传。

### 窗口置顶：`C + T`

按一下把**当前窗口**钉在最上层，再按一下放开。这一块是**直接移植 PowerToys 的
AlwaysOnTop 模块**（窗口模型、事件、定时器、D2D 绘制都同源，见
[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md#窗口置顶pincppct)）：

- 钉住的窗口外面套一圈**圆角边框**：粗细 2px（随显示器 DPI 缩放）、跟随系统
  **强调色**、Win11 上圆角半径跟随窗口自己的圆角设置（Win10 直角）。
  PowerToys 的几何是"环从窗外 1px 起、向内压 1px"，所以看到的是约 1px 的细线。
- 钉住响一声 `Speech On`，放开响一声 `Speech Sleep`（都是系统自带音效，
  跟随"声音方案"，静音方案下自动安静）。
- 边框不抢焦点、点它不会有任何反应（与 PowerToys 同款：边框窗 `WS_DISABLED`
  且不改光标）；它只在外挑的那一两像素上占位，不影响窗口本身的操作。
- 可以同时钉多个窗口（上限 32 个）；托盘菜单的**取消全部置顶**一次全放，
  没有置顶时该项置灰。
- 边框跟随窗口移动 / 缩放 / 最大化 / 还原；窗口最小化时边框隐去，恢复时
  重新置顶并画回来；切到别的虚拟桌面时边框也跟着隐去。
- 不接管桌面 / 任务栏 / 本程序自己的窗口；命中 `[AutoDisable]` 时整段不介入。
- 退出或重启程序会**解除全部置顶**（窗口回到原来的层级）；**暂停映射不会**
  动已钉的窗口 —— 暂停只停按键。

> 目标窗口以管理员身份运行时，非提权的本程序改不动它：会弹托盘气泡提示，
> 需要置顶这类窗口请开 `RunAsAdmin = 1`。

### 单键切输入法（单击 Caps / 左右 Shift）

**单击**（按下后很快松开、不做别的）把输入法**强制**切到固定一边，不存在"按反了"：

| 单击 | 强制切到 | 配置项 |
| --- | --- | --- |
| `CapsLock` | 中文 | `ImeCapsMode` |
| 左 `Shift` | 英文 | `ImeLShiftMode` |
| 右 `Shift` | 中文 | `ImeRShiftMode` |

- 模式值：`0` = 不处理、`1` = 中文、`2` = 英文，三键各自独立。
- **前提是当前不是英文键盘**：本程序只切中/英状态，不替你换键盘布局；停在英文键盘上时三键都没反应（刻意行为）。
- "单击"判定：Caps = 按住期间没触发任何 `C+` 动作（无时间上限）；Shift = 期间没按别的键且 ≤ 300ms（不影响 `Shift+A` 这类组合）。
- 遵守 `[AutoDisable]` 名单；切换只改中英位，保留全角 / 符号等其它转换模式。

```ini
[General]
ImeCapsMode   = 1   ; Caps    -> 中文
ImeLShiftMode = 2   ; 左Shift -> 英文
ImeRShiftMode = 1   ; 右Shift -> 中文
```

### 滚轮（按住 C）

| 组合 | 行为 |
| --- | --- |
| `C + 滚轮` | 快速滚动：滚一格当 N 格（`WheelScrollMul`） |
| `C + Alt/D + 滚轮` | **持续滚动**：滚一下就一直滚，同向再滚逐档提速，反向滚立即停 |
| `C + Shift + 滚轮` | 横向滚动（方向与系统约定一致） |

判定顺序：Shift（横向）→ Alt/D（持续）→ 快速滚动。

持续滚动细节：按任意键 / 鼠标键终止（系统自动重复不算）；松开 C **不**终止；超过 10 分钟无操作自动停。手感是"不足一格的小刻度"（像触控板），不累积小刻度的程序写进 `[NoSmoothScroll]` 改发整格。

### 按键帮助：`C + F1`

**按住** `C + F1` 浮出一张半透明键位图（完整键盘，功能印在键帽上），松开任一键即消失。

- 不抢焦点，可以一边按着看一边操作；底部列出滚轮、输入法、拖动这些"非单键"功能。
- 由独立的 `CapsEnhanceHelp.exe` 画（主程序崩了也不会留下关不掉的图）；单击 Caps / Shift 三条的文案跟随 `Ime*Mode` 配置。
- 直接双击 `CapsEnhanceHelp.exe` 可单独看图：显示、点一下关闭，3 分钟自动收。

### 日志：C + 反引号

- 开始 / 结束记录，日志写在 exe 同目录 `log\` 下，**每次记录新建一个文件**；平时不写。
- 开始 / 结束各响一声不同的系统提示音（都走系统声音方案，可改可静音）。
- 结束时弹的托盘气泡**可点击**：打开 `log\` 目录并选中这份日志（与 `C+F3` 同一条 shell 链路）。
- 记录期间会写焦点控件的文本样本（前 160 字符）与跳转位置 —— **敏感内容慎开**。
- 启动时静默采集一次环境基线（位宽 / 钩子 / 权限 / 键盘布局 / UIA 可用性），记录时一并输出。

## 配置（CapsEnhance.ini）

与 exe 同目录，首次运行自动生成带注释的模板。`;` 开头是注释；缺失的键启动时自动补齐。

改配置：托盘菜单 → **设置**（表单式编辑器，`Ctrl+S` 或"保存并重启"写回；写回是**增量**的，你的注释与未知键都保留）→ 保存后自动重启本体生效。手动改 ini 则用托盘"重启程序"或 `CapsEnhance.exe --restart`。

### `[General]`

| 配置项 | 默认 | 作用 |
| --- | --- | --- |
| `RunAsAdmin` | `0` | 以管理员运行（弹 UAC）。只有要拖动 / 操作管理员权限的窗口才需要 |
| `LogMaxKB` | `2048` | 日志大小上限（KB），超限保留最近一半；`0` = 不限制 |
| `WheelScrollMul` | `3` | `C+滚轮` 快速滚动倍数；`0/1` = 关闭，上限 `16` |
| `AutoScrollInterval` | `1500` | 持续滚动初始速度（毫秒/格，越大越慢），`100..60000` |
| `AutoScrollFastMs` | `60` | 持续滚动最快速度（毫秒/格，越小越快），`20..60000` |
| `WheelHScrollMul` | `1` | `C+Shift+滚轮` 横向倍数；`0` = 关闭，上限 `16` |
| `AllowScintillaRead` | `1` | 允许读 Scintilla 程序内存实现瞬跳；`0` = 退回 UIA / 原生 `Ctrl+方向` |
| `MaxArrowSteps` | `4` | 逐格发方向键的步数上限（只约束"直接置位不可用"的场合；支持的控件 3 步起就走瞬跳）；`0` = 不限制（上限 256） |
| `OverStepMode` | `1` | 逐格到上限后：`0` = 只发一个方向键；`1` = 改发 `Ctrl+方向` |
| `ImeCapsMode` / `ImeLShiftMode` / `ImeRShiftMode` | `1` / `2` / `1` | 单击 Caps / 左 Shift / 右 Shift 切中文 / 英文 / 中文；`0` = 不处理 |
| `HyperPassthrough` | `0` | Hyper 透传（进阶，默认关）：按下**未映射键**时才临时按住右侧 `RWin+RCtrl+RShift`（**不含 Alt**），该键以 Hyper+X 的形态送出 |

> **Hyper 透传是给谁用的**：外部自动化工具（AutoHotkey 等）可以把 `>#^+某键` 绑成 Hyper 热键，例如 AHK 里 `>#^+g::` 对应按住 Caps 再按 G（G 未映射）。
>
> **它是「懒按下」的**：按住 C 期间三键并不按着，只有按下未映射键的那一刻才按、最后一个这类键抬起就抬。所以 `Caps+滚轮`、`Caps+鼠标` 全程不带修饰键（不会变成 Shift+滚轮/Shift+点击）。代价是未映射键由本程序**重放**（物理键被吞掉）：过滤注入输入的程序（部分游戏、少数安全软件）拿不到它；键的自动重复也由我们转发。**从旧版升级注意**：修饰键集去掉了 `RAlt`（Win+Alt+* 被系统占了一批），AHK 脚本里的 `>#^!+x` 要改成 `>#^+x`，否则绑不上。
>
> 已映射键（J/K/…）不受影响，仍是拦截后重发；按住 Hyper 键的同时触发映射动作时，发键前会临时摘掉三键（否则方向键会变成 Win+方向把窗口贴边）。系统组合键基本不会误触——Win+E、Win+数字这类热键要求修饰键精确匹配，多按的修饰键会让它们失配（`test/hyperprobe*.cpp` 实测过这一条）；Win+L 例外但 L 是映射键，够不到。**但 `Win+Ctrl+Shift+字母` 现在会精确匹配**，其中 `Win+Ctrl+Shift+B` 是「重置显卡驱动」（屏幕黑闪、全屏程序可能掉）——不用 Hyper+B 的话在 AHK 里加一行 `>#^+b::return` 兜底即可。

> 想换增强键 / 选区键？不支持：`Alt+D` 与 `F` 属于和弦语法本身（刻意为之，理由见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)）。

### 名单段

共五份，每行一条，完全匹配、大小写不敏感，`.exe` 后缀可省，`;` 开头是注释。设置程序的"选取窗口"可取：进程名单取进程名、窗口类名单取类名。

| 段 | 作用 |
| --- | --- |
| `[NativeWordJump]` | 这些程序不做文本探测，直接发 `Ctrl+←/→`（适合读不到文本或读不准的） |
| `[AutoDisable]` | 前台是这些程序时**整段不介入**：CapsLock 恢复正常，滚轮也不放大（全屏游戏 / 远程桌面 / 虚拟机）。按下 Caps 那一刻判定，切走即恢复 |
| `[NoSmoothScroll]` | 持续滚动对它们只发整格（默认小刻度它们不累积，表现为滚了不动） |
| `[DragWindowBlacklist]` | 拖动黑名单，按**窗口类名**（写类名本身） |
| `[DragProcessBlacklist]` | 拖动黑名单，按**进程名** |

## 注意事项 / 常见问题

- **Caps 必须第一个按下**：`Alt + C + J` 这种反着按不生效（修饰键会卡住）；`C + J + Alt`（先 J 后补 Alt）那一次就是普通左移 —— 不做补正换来"按下即响应"。
- **`C + Q` 没反应**：前台是桌面 / 任务栏 / 本程序自己，或命中 `[AutoDisable]`，或前台是全屏窗口、或是已最大化且光标就在本屏 —— 都是故意不挪。记录模式（C + 反引号）下 `[窗口]` 行有判定结果。
- **自动屏蔽没生效**：判据是前台窗口所属进程，进程名要和任务管理器"详细信息"页的映像名一致；后台 / 服务的窗口不算前台。
- **WPS**：只支持 `wps.exe`（表格 / 演示的对象模型不同）；`RunAsAdmin=1` 时自动走一个普通权限小进程代读。不生效先看日志的 `[桥]` / `[桥WPS]` 段。
- **体量上限**：经典 Edit 通道 64000 字符、Scintilla 2 MB（字节）、WPS 100000 字符，超出直接退回原生 `Ctrl+方向`。
- **重启 / 退出会清卡键**：对所有键补发抬起（`CapsLock` / `NumLock` / `ScrollLock` 这类开关键除外），**不限于本程序造成的**——别的程序崩溃留下的卡键同样清掉（判定"系统认为按着 && 钩子没见到你物理按下"，所以你正按着的键不受影响）。已知边界：**启动**那一遍比较保守（启动前就按着的键分不清"你在按"还是"已卡住"，一律保护），上次崩溃残留的修饰键卡键若没被清掉，**再重启一次**即可。
- **排障命令**：`CapsEnhance.exe --restart` 请求运行中的实例重启（本体没在跑时会照常启动）。
- **卸载** = 删目录。只落地 `CapsEnhance.ini`、`log\`、进程内钩子（退出即消失）。
