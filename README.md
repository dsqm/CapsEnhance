# CapsEnhance

Windows **CapsLock** 快捷键增强程序。按住 `CapsLock` 当作修饰键，把 `CapsLock` 变成一个贴身的动作键盘 / 滚动控制器 / 阅读工具。

- 底层键盘 + 鼠标钩子，无第三方依赖，便携单文件（MSVC x64；源码按 C++ 编译，见[构建与测试](#构建与测试)）。
- 常驻系统托盘，可随时**暂停 / 重启 / 退出**。
- 不写注册表、不改系统设置，卸载 = 删掉整个目录。

---

## 快速开始

1. 把 `CapsEnhance.exe` 与 `CapsEnhanceSettings.exe` 放到同一个目录，双击 `CapsEnhance.exe` 运行。
2. 托盘会出现程序图标（首次可能收进托盘"隐藏图标"溢出区，从任务栏设置里拖出来即可常驻）；从托盘菜单可**暂停映射 / 打开设置 / 重启程序 / 退出**。
3. 需要管理员权限时，在配置里打开 `RunAsAdmin = 1`（**默认关闭**，见[配置](#配置-capsenhanceini)）。

> **CapsLock 会被本程序拦截**：按住才是光亮键的"映射模式"，单击或长按不做任何事、也不触发真的 CapsLock。需要大小写切换时，用 `CapsLock + Tab` 发送一次真实的 CapsLock。

## 基本映射

按住 `CapsLock`（以下简称 **C**）进入映射模式，按下面的触发键生效；松开 C 恢复原样。

| 触发键     | 动作                  |
| ------- | ------------------- |
| `I`     | ↑                   |
| `J`     | ←                   |
| `K`     | ↓                   |
| `L`     | →                   |
| `P`     | Home                |
| `;`     | End                 |
| `R`     | Backspace           |
| `W`     | Delete              |
| `Space` | Enter               |
| `Q`     | 把当前窗口挪到鼠标光标处（支持多屏幕） |
| `F3`    | 打开当前程序所在文件夹（并选中它的 exe） |
| `Tab`   | 发送真实 CapsLock       |
| `N`     | 按词向左跳转              |
| `O`     | 按词向右跳转              |
| **`**   | 开始\结束记录日志           |

### 增强键与选区键

| 键                | 作用                                                    |
| ---------------- | ----------------------------------------------------- |
| **`D` 或左 `Alt`** | **增强键**：`C + J` = 左移一格，`C + D + J` = 连续左移 3 格         |
| **`F`**          | **选区键**：相当于按住 `Shift`，`C + F + J` = `Shift + ←`（扩展选区） |

> 例：`C + D + F + J` = 连续 3 次 `Shift + ←`（一次选中 3 个字符）。

### 按词跳转：`N` / `O`

`C + N` / `C + O` = **按词向左 / 右跳**。它不只是"Ctrl + 方向键"，而是**读取目标程序的真实文本**、按"连续同类认为是一个词"的边界智能跳转，在中文、英文、数字、生僻字混排时表现更稳定：

- 左右都停在"词的边界"（类型切换处），默认**不跨行**，只在行头/行尾才跨到相邻行。
- 例：`你好，世界1234abcd中国` → 会停在 `你好，|世界|1234abcd|中国`。
- 跳转距离小、或程序不支持"直接置位"时，改为**逐格发送方向键**，期间可随时松开 C 或改道打断。
- 程序读不到文本时自动退回原生 `Ctrl(+Shift)+方向键` 兜底。

已支持读取文本的程序类型：经典 Edit / RichEdit / **EmEditor**、Scintilla 系（Notepad3 / Notepad++ / SciTE）、UIA（QQ、Edge 等 Chromium/WinUI 控件）、IAccessible2、以及 **WPS 文字**（走 COM 自动化）。

### 窗口挪到光标处：`Q`

规则：

- 落点是"**窗口左上角对齐光标**"，再把整窗钳进**光标所在那块显示器的工作区**（已排除任务栏） 所以挪完一定**整窗可见**；窗口比工作区还大时按左上角对齐（至少标题栏可见）
- 光标落在两块屏之间的缝里、或某块屏刚被拔掉（坐标悬空）时，按"**最近**的那块屏"处理。
- **最大化的窗口**：先还原 → 挪到光标那块屏 → 再重新最大化。结果是"还是最大化，只是换了块屏"，不会顺手取消你的最大化状态；最小化的窗口会被还原成普通窗口挪过来。
- 如果某个程序挪过去之后**又把自己挪走**（带吸附 / 跟随鼠标行为的启动器、面板类小工具），会**回读左上角**再补发一次（最多 3 次），所以正常仍是一次点击到位；仍不行会把实际落点写进日志（C + \` 记录模式）。

- 本程序不改变前台窗口，所以按 `C + Q` 时前台就是你想挪的那个程序。

### 打开程序所在文件夹：`F3`

对**当前程序**（前台窗口所属的那个程序）按 `C + F3` = 打开它**所在的文件夹**并选中它的 exe —— 等价于资源管理器右键菜单里的「打开文件所在的位置」。

- 用的是 Windows 的**标准 shell 接口**（`SHParseDisplayName` + `SHOpenFolderAndSelectItems`），"打开文件夹并选中一项"这件事由系统当前的默认文件管理器执行 —— **不是拼 `explorer.exe /select,` 命令行**，所以换了第三方文件管理器也照样能用。
- 目标是**按下键那一刻**的前台窗口（不是等执行时再读一次），按键后立刻切窗口也不会开错。
- 这条动作**单发**：长按不会重复，也不吃 `D` / `F` 两个修饰键（它跟光标、选区都无关）。
- 打不开时会弹一次托盘气泡说明原因，共三种：前台是**桌面 / 任务栏**（它没有"所在文件夹"）；**受保护进程**（System 之类）或进程已退出；**UWP 应用**的安装目录解析不到。UWP 程序的前台窗口属于宿主 `ApplicationFrameHost.exe`，本程序会先找到它下面那个真正属于该应用的窗口、再按它的进程取路径；**解析不到就不开**，而不是退而打开 `System32`。
- 已知限制：目标文件夹**已经在别处打开**时，系统仍可能新开一个窗口（不复用已开的那个）。这是该接口的既有行为，不是本程序的选择。

### 按住 Caps 拖左键：拖动当前窗口

按住 `Caps` 时按下**左键**并拖动 = 移动**光标下的那个窗口**（不必先把鼠标挪到标题栏）。松开左键、或松开 `Caps` 就结束。

- 目标是**光标下的顶层窗口**：不要求它有焦点，拖完也不抢焦点；
- **最大化的窗口**会先还原成普通窗口再跟手（与 AltSnap 的默认行为一致）；
- 全屏窗口、最小化窗口、桌面与任务栏**不接管**，左键原样透传；
- **最大化窗口要先拖出 20px** 才开始移动；
   普通窗口按下即跟手，无阈值；
- 点击**不穿透**：`Caps + 左键` 不会传给目标程序（拖动时也不会误选文字）；

## 单键切换输入法（Caps / 左右 Shift）

**单击**（按下后很快松开、不做别的）这三个键，可以把输入法**强制**切到固定一边 —— 不看当前是中是英，所以不存在"按了没反应 / 按反了"：

| 单击            | 强制切到        | 配置项              |
| ------------- | ------------ | ---------------- |
| `CapsLock`    | **中文**       | `ImeCapsMode`    |
| **左** `Shift` | **英文**       | `ImeLShiftMode`  |
| **右** `Shift` | **中文**       | `ImeRShiftMode`  |

几个要点：

- **前提：当前不是英文键盘**。本程序只切"当前输入法"的中/英状态，**不替你换键盘布局**（那等于改动你的输入环境）。所以停在英文键盘（主语言 `0x09`）上时，这三个键都是没反应 —— 这是刻意的行为，不是失灵。

- **"单击"的判定，Caps 与 Shift 不一样**：
  - `Caps` 是和弦首键，所以"按住期间没触发任何 `C+` 动作"就算单击 —— **没有时间上限**，按住发呆再松开也算。
  - `Shift` 是系统也在用的真修饰键，所以必须是"**期间没按别的键**"**且**"**按下时长 ≤ 300ms**"。用来组合快捷键（`Shift+A`、输入法自己的 `Shift` 切中英）时不会被误判。
- **当前是英文键盘时，三个键都不处理**：判定是前台窗口的键盘布局主语言（`0x09` = 英文）。本程序只切**当前输入法**的中/英状态，**不会替你换键盘布局** —— 所以停在英文键盘上按 Caps 就是没反应（这是刻意的，不是失灵）；想让它动，先用系统快捷键切到中文输入法。
- **遵守 `[AutoDisable]` 黑名单**：命中的程序在前台时，三个键都不处理（与"整段不介入"同一份名单、同一语义）。
- 切换只改必要的那一位（`IME_CMODE_NATIVE`）与输入法开关，**保留你原有的其它转换模式**（全角/符号等）；切换失败会把读到的值写进日志（`C + \`` 记录模式）。
- 切换跑在**独立线程**上：跨进程 IME 消息可能要等上百毫秒，绝不能堵住键盘钩子。

每个键的模式值：`0` = 不处理、`1` = 切中文、`2` = 切英文（超过 2 会钳到 2）。三个键**各自独立**，互不影响。

```ini
[General]
ImeCapsMode   = 1   ; Caps    -> 中文
ImeLShiftMode = 2   ; 左Shift -> 英文
ImeRShiftMode = 1   ; 右Shift -> 中文
```

> 想让某个键彻底不插手输入法，把对应项设成 `0` —— 该键仍可正常用于组合键（Shift 也仍是普通 Shift）。

## 鼠标滚轮（按住 C）——三种行为

按住 `CapsLock` 时滚动鼠标滚轮有三条行为，互不共用配置项：

| 组合               | 行为                                       |
| ---------------- | ---------------------------------------- |
| `C + 滚轮`         | **快速滚动**：滚一格当 N 格（倍数见 `WheelScrollMul`）  |
| `C + Alt/D + 滚轮` | **持续滚动**：滚一下就自己一直滚，同向再滚**逐档提速**，反向滚一下立即停 |
| `C + Shift + 滚轮` | **横向滚动**：滚轮上下 = 左右滚动（方向与系统约定一致）          |

判定顺序：`Shift` 优先（横向）→ `Alt/D`（持续滚动）→ 否则快速滚动。

### 持续滚动（C + Alt/D + 滚轮）

滚起来就可以松手阅读：

- **向一个方向滚一下**即开始持续滚动（从最慢档起步），**滚轮是否还在动无关**；
- **同向继续滚** = 逐档提速，直到最快上限；
- **反向滚一下** = 立即终止，并重置速度；
- **按任意键 / 鼠标键**也终止（系统自动重复不算），松开 C / 修饰键**不再**终止；
- 超过 10 分钟没有调速会自动停（防止人走开了还在滚）。

## 配置（CapsEnhance.ini）

与 exe 同目录，首次运行自动生成**带注释的模板**。改完有两种生效方式：

- 托盘菜单 → **设置**（推荐）：打开 `CapsEnhanceSettings.exe` —— 一个**表单式**的配置编辑器（布尔项是勾选框、数值项是数字框、五份名单各是一个可增删的列表；列表那一行还有"选取窗口"，取到的值先填进输入框，点"添加"才入名单）。点"保存并重启"（或 `Ctrl+S`）即写回 ini 并重启本体。写回是**增量**的：你写的注释、我们不认识的段与键都原样保留，BOM 与行尾风格也跟随原文件。
- 手动编辑 ini → 托盘菜单**重启程序**（或命令行 `CapsEnhance.exe --restart`）。

格式约定：

- INI 风格：`;` 开头的行是注释，空行忽略，`[段名]` 用于分段。
- 老配置缺失的键会在启动时**自动补齐**，已有内容原样保留。

### `[General]` 项

| 配置项                  | 默认     | 作用                                                                                            |
| -------------------- | ------ | --------------------------------------------------------------------------------------------- |
| `RunAsAdmin`         | `0`    | 以管理员身份运行（会弹 UAC；取消则按普通权限继续）。**只有要拖动/操作那些以管理员运行的窗口时才需要设 1**（UIPI 会拦住低权限进程对高权限窗口的 SetWindowPos） |
| `LogMaxKB`           | `2048` | 日志大小上限（KB），超过保留最近一半；`0` = 不限制                                                                 |
| `WheelScrollMul`     | `3`    | `C+滚轮` 快速滚动的倍数（滚一格当 N 格）；`0/1` = 关闭，上限 `16`                                                   |
| `AutoScrollInterval` | `1500` | 持续滚动的**初始**速度（毫秒/格，越大越慢），范围 `100..60000`                                                      |
| `AutoScrollFastMs`   | `800`  | 持续滚动的**最快**速度（毫秒/格，越小越快），范围 `20..60000`；与上一项各自独立                                              |
| `WheelHScrollMul`    | `1`    | `C+Shift+滚轮` 横向倍数；`0` = 关闭，上限 `16`                                                            |
| `AllowScintillaRead` | `1`    | 是否允许读取 Scintilla 程序（Notepad3/Notepad++）的进程内存来实现瞬跳；设 `0` 退回 UIA / 原生 Ctrl+方向                   |
| `MaxArrowSteps`      | `4`    | 按词跳转逐格发送达到多少步就触发 `OverStepMode` 策略（4 = 4 格及以上瞬跳、3 格以内逐格）；`0` = 不限制（一律逐格）                      |
| `OverStepMode`       | `1`    | `0` = 只发一个方向键；`1` = 改发 `Ctrl+方向`（由目标程序自身按词跳转）                                                 |
| `ImeCapsMode`        | `1`    | 单击 Caps 时把输入法强制切到哪：`0` = 不处理、`1` = 中文、`2` = 英文（详见[单键切换输入法](#单键切换输入法caps--左右-shift)）      |
| `ImeLShiftMode`      | `2`    | 单击**左** Shift 同上（默认切英文）。**当前是英文键盘时三个键都不处理**                                            |
| `ImeRShiftMode`      | `1`    | 单击**右** Shift 同上（默认切中文）。同上：**当前是英文键盘时三个键都不处理**                                        |

> 想换增强键或选区键？不支持。`Alt + D` 与 `F` 属于"和弦语法"本身，改它等于改功能，所以不做成配置开关（这部分属于本项目刻意为之，具体理由见开发者文档）。

### 名单段

共五份。`[NativeWordJump]` / `[AutoDisable]` / `[NoSmoothScroll]` / `[DragProcessBlacklist]`
每行一个**进程名**；`[DragWindowBlacklist]` 每行一个**窗口类名**（就写类名本身）。

匹配规则：**完全匹配**、大小写不敏感；进程名的 `.exe` 后缀可写可不写；`;` 开头的行是注释。
（设置程序里点"选取窗口"会按名单取对应的东西 —— 进程名单取进程名，窗口类名单取类名。）

#### `[NativeWordJump]`：改用程序自己的按词跳转

对"读不到文本"或"读到的文本坐标与实际光标位置不符（按词跳转超调、光标乱飘）"的程序，把进程名写进来：`Caps+N/O` 就不做文本探测，直接发 `Ctrl+←/→`。

#### `[AutoDisable]`：这些程序在前台时自动让开

命中的程序**在前台**时，本程序整段不介入：CapsLock 恢复正常功能，`C+任意键` 照常打字，`Caps+滚轮` 也不放大。适合自己吃掉了 CapsLock、或 Caps 组合与其快捷键冲突的程序（全屏游戏、远程桌面、虚拟机、部分 IDE）：

```ini
[AutoDisable]
mstsc.exe
```

> 判据是"**前台窗口**所属进程"，且只在**按下 Caps 那一刻**判定 —— 切到别的窗口立刻恢复，不需要重启。

#### 拖动黑名单：`[DragWindowBlacklist]` 与 `[DragProcessBlacklist]`

按住 Caps 拖左键时，命中名单的窗口**不被接管**（左键原样透传）。**两份名单各管一头**：

| 段                        | 判定依据        | 条目写法                  |
| ------------------------ | ----------- | --------------------- |
| `[DragWindowBlacklist]` | 窗口**类名** | 类名本身，如 `Shell_TrayWnd` |
| `[DragProcessBlacklist]` | 窗口所属**进程名** | `name.exe`（`.exe` 可省） |

两处细节：

- 条目里**没有"标题"这一维** —— 读另一个进程的标题要发 `WM_GETTEXT`，那是跨进程 IPC，而判定发生在鼠标钩子上。所以条目就是名字本身（不带任何前缀）。
- **两份名单各自独立**：谁的段没写，就用谁的内置默认；段一旦存在就以文件为准 —— 想把某份名单清空，把它下面那几行删掉即可。

> **`Caps+左键` 拖不动某些窗口、或窗口比光标跑得快？** 那是坐标空间的问题（低级鼠标钩子给物理像素，
> 而本程序若被系统当成"不感知 DPI"就会用虚拟坐标）。本程序启动时已声明 Per-Monitor V2，正常情况下
> 不会发生。真遇到时看记录模式（`C + \``）下的启动基线：`坐标空间 = 物理(与钩子一致)` 是正常的。

#### `[NoSmoothScroll]`：持续滚动只发整格

持续滚动默认只发"不足一格"的小刻度（手感像触控板）。少数程序不累积这种小刻度，表现为**滚了却完全不动** —— 把它的进程名写进来，就只对它改回每次发整格：

```ini
[NoSmoothScroll]
someapp.exe
```

## 日志与诊断

- 按 C + \` 开始 / 结束日志记录 ，日志写在 exe 同目录的 `log\` 子目录里，**每次开始记录新建一个** `CapsEnhance-<日期>-<时间>.log`（本次内容从第一行开始，不会混进旧记录）。平时不写日志。
  
  > **隐私提示**：记录期间会把焦点控件的文本样本（前 160 字符）与按词跳转位置写进日志，敏感内容请斟酌是否开启。

- 启动时静默采集一次"环境基线"（进程位宽、钩子状态、OS 版本、管理员权限、键盘布局、UIA 可用性等），记录日志时一并输出，便于排查"某个窗口用不了"。

- 排障辅助命令行：
  
  - `CapsEnhance.exe --restart`：请求正在运行的实例重启（等同托盘"重启程序"）。**本体没在跑时它会照常启动** —— 设置程序保存配置后用的就是它，脚本里也能用。

## 注意事项 / 常见问题

- **CapsLock 被拦截**：需要真实大小写切换时用 `C + Tab`，或从托盘点"暂停映射"。某些程序（全屏游戏 / 远程桌面）需要一直保留真实的 CapsLock —— 把它的进程名写进 `[AutoDisable]`，它到前台时本程序会自动让开。
- **设置了自动屏蔽却还在生效**：判据是**前台窗口所属进程**，服务/后台进程的窗口不算前台；进程名要与任务管理器里"详细信息"页的**映像名称**完全一致（不含路径）。
- **`Caps + Q` 没反应**：挪的是"焦点程序的**顶层**窗口"—— 前台是桌面/任务栏、或前台就是本程序自己（托盘菜单开着）时不生效；命中 `[AutoDisable]` 的程序也照常让开、不介入。记录模式（`C + \`` ）下会写一行 `[窗口]`，里面有它算出的落点。
- **必须是 C 打头的组合**：`Alt + C + J` 这种"反着按"不生效 —— 修饰键的按下早已被系统看到，反着按会导致修饰键"卡住"。记一条：**Caps 必须是第一个按下的键**。
- **修饰键要先按住，再按动作键**：`C + Alt + J`（先按 Alt，再按 J）才是"增强的左移"。`C + J + Alt`（先按 J 再补 Alt）那一次就是普通左移 —— 顺序反过来不做补正，按下的那一刻是什么状态就发什么，好处是动作**按下即响应**（不再有约 50ms 的等待）。
- **单实例**：同时只允许一个实例运行，重复启动会提示"已在运行中"。
- **WPS 文字**：只支持 `wps.exe`（表格 / 演示的对象模型不同）。`RunAsAdmin=1` 时会自动拉起一个普通权限的小进程（"降权桥"）代读 —— 因为管理员进程看不到普通权限 WPS 的自动化对象。若在 WPS 里按词跳转不生效，先看日志里有没有 `[桥]` / `[桥WPS]` 段。
- **体量上限**：经典 Edit 通道只处理 **64000 字符以内**的文档，超出直接退回原生 `Ctrl+方向`；Scintilla 上限 **2 MB**（字节），WPS 上限 **100000 字符**。按词跳转由此"一步退到底"，不会降级成慢速逐格。
- **卸载** = 删掉整个目录。它只落地三样东西：`CapsEnhance.ini`（配置）、`log\` 子目录里的日志（记录模式才写）、进程内的钩子（退出即消失）。不装服务、不开机自启、不写注册表。

## 构建与测试

依赖 **MSVC x64**（Windows 10/11），工具链由 `build_env.bat` 统一定位。所有源文件按 **C++** 编译（`/TP`）：代码风格仍以 C 为主（COM 走 `CINTERFACE` 的 C 接口形态），切到 C++ 是为了能逐文件引入类型安全与资源管理的 C++ 写法，而不是一次性重写。

```bat
build.bat    rem 生成 bin\CapsEnhance.exe 与 bin\CapsEnhanceSettings.exe
```

程序图标（托盘 / 窗口 / 资源管理器）来自 `res\app.ico`（16/24/32 三帧，由 `res\icon*.png` 打包，嵌入为 exe 资源 #1）。换图标：替换 `res\` 下的三张 PNG 重新跑一次 `python` 打包脚本或用任意 ICO 工具生成同名 `app.ico` 即可。

两个 exe 必须放在同一目录：托盘菜单的"设置"按**同目录**找 `CapsEnhanceSettings.exe`，设置程序也按同目录找 `CapsEnhance.ini` 与 `CapsEnhance.exe`。

设置程序的源码是 `settings/settings.c`：独立 exe（本体主线程是键盘钩子的宿主，不能同时拥有设置窗口），但它**链接 `src/config.c`** —— 值域、键名与钳制规则都只有一份，界面里不会写出"配置层不接受的值"。设置窗口是**高 DPI 感知**的（Per-Monitor V2，跨屏拖动会按新 DPI 重排并重建字体）。

运行测试与诊断工具（均在 `test\` 目录下）：

```bat
build_nav.bat      rem 按词跳转测试：算法单测 + Scintilla/Edit 通道集成 + 配置解析
build_test.bat     rem 和弦引擎回归测试
build_dbg.bat      rem Debug CRT（/MTd）版：越界写这类 bug 只有这里拦得住
build_analyze.bat  rem 静态分析（/W4 + /analyze）
build_keytest.bat  rem 诊断工具：keytest / uiprobe / memtest / restarttest ...
build_wpsjump.bat  rem WPS 通道真机检查（没装 WPS 自动跳过）
```

CI（GitHub Actions，`.github/workflows/ci.yml`）：push / PR 时在 `windows-latest` 上依次跑单测集成 → Debug 守卫 → 诊断工具构建 → 静态分析 → 重启/日志进程级检查 → WPS 真机检查（无 WPS 自动跳过）→ 构建并把 exe 上传为 artifact。

> 开发者想要架构、实现原理、排障细节与各模块职责，见 **[docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)**。
